Fazer um website

Oct 21, 2022

Este post server maioritariamente para ficar mais confortável a postar online. Também estou a usar este post para partilhar como construi esta página.

Encontrar um sítio para colocar o website

Originalmente, procurei maneiras de “hospedar” um website em casa ou talvez “na nuvem”. Mas todas as opções que encontrei requeriam algum tipo de conhecimento em como gerir um website. Depois, aprendi sobre GitHub Pages que me pareceu uma boa opção para comecar e aprender como fazer isto.

Como pôr isto online

Como foi descrito no link, é tão simples como criar um repositorio com o nosso username, e podemos comecar a trabalhar Por exemplo, para fazer este website, criei o repositório marioasmira/marioasmira.github.io que está a ser publicado em marioasmira.github.io. Este website, no entanto, precisaria de ser escrito em HTML e CSS, e não sou super familiar com estas línguas… Decidi então seguir a sugestão dada pelo link e usar Jekyll.

Jekyll é uma forma interessante de transformar ficheiros de texto Markdown num website estático, que é exatamente o que eu queria. Depois de escolher onde e como publicar estas páginas, foi relativamente simples seguir os guias.
